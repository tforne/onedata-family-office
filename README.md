# OneData Family Office Landing

Proyecto de landing corporativa en **Next.js + Tailwind CSS**.

## Cómo arrancar

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Qué incluye

- Landing corporativa completa
- Estructura por componentes
- Tailwind CSS
- Secciones de hero, capacidades, IA, beneficios, sectores y contacto

## Siguientes mejoras recomendadas

- Sustituir el logo temporal `OD` por el logo real
- Añadir capturas reales del producto
- Conectar el formulario a un backend o CRM
- Ajustar branding y metadatos SEO
